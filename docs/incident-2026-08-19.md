# Incident: 2026-08-19 — SEED_KERNEL の 11 日ずれ

## 事実

- `rei-memory-mcp` を実装している最中、ローカル HEAD 由来の SEED_KERNEL は **1,677 理論**
- 一方、 `claude.ai/remote-devices` 経由の `rei-aios` MCP は **1,675 理論** を返していた
- deploy は 2026-08-06。**11 日間、誰も気づいていなかった**
- 気づけたのは、藤本さんが両方の数字を偶然見比べたから

## 何が問題だったか

「ずれていたこと」ではない。**ずれに気づけなかったこと** である。

同じ対象 (SEED_KERNEL) に対する二つの経路 (SQLite direct read / MCP over
remote-devices) を、機械的に突き合わせる仕組みが存在しなかった。
Claude セッションもこの gap を認知しない。人間が両方叩いて初めて見える。

## このリポジトリの位置づけ

この事故に対する具体的な対策として `rei-meta-mcp` を作った。

- `meta_check_coherence("seed_kernel")` が二経路の指紋 (record_count +
  id_set_hash + content_hash) を比較し、`divergent` verdict を返す
- 到達できない source は `unreachable` として毎回明示される (§4)
- 「気づけない」状態を機械の default にしない

## 意図的にやらないこと

- **自動修復しない** — どちらが正しいかの判断は人間が行う
  - 今回は「ローカルが正しく remote が stale」と自明に見えるが、逆もあり得る
  - 判断をメタ層に持ち込むと、判断ミスの検出手段が消える
- **history 永続化しない** (Phase 1) — メタ層が第三の真実になるのを避ける
- **圏論の名前を装飾に使わない** — 対象・射・等化子・合成・恒等射の 5 つ
  だけ荷重を負う。関手・随伴・モナドは書かない (必要になれば追加する)
